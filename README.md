# Почасовое обновление цен

## 1. Что уточню перед реализацией

1. По каким полям считаем предложения одинаковыми? Как отличаем аналоги, другую фасовку, б/у детали и несовпадения по наличию?
2. Откуда берём минимальную цену и допустимое изменение? Кто утверждает рекомендацию, выходящую за допустимый диапазон?
3. Сколько независимых источников нужно для расчёта по артикулу? Какой возраст снимка допустим и какой сбой считаем критичным?
4. Как сейчас Excel попадает в генератор прайсов? Где хранятся действующая версия прайса и ручные правки менеджеров?
5. Какие артикулы возьмём в пилот и по каким показателям решим, что можно включать автообновление?

**В первую очередь уточню сопоставление и ценовые ограничения.** Сопоставление определяет ключ артикула и то, какие предложения вообще попадут в расчёт. Ценовые правила задают порог автопубликации, порядок ручной проверки и способ сохранить ограничения по марже.

**Для пилота** считаю, что позиции сопоставляются по производителю и артикулу с учётом фасовки. Текущая и минимальная цены приходят из действующей системы, а достаточную свежесть и покрытие согласуем до первого включения.

## 2. Как запускаю рядом с действующим прайсом

Планировщик каждый час запускает сбор по площадкам с отдельным тайм-аутом на источник. В существующей базе сохраняю снимки с ID запуска, площадкой, временем наблюдения и результатом сбора. При подготовке данных привожу валюту, НДС и единицу товара к одному виду и исключаю несовпавшие позиции, собственный магазин и неподходящую доставку. По каждому артикулу проверяю свежесть и покрытие источников. Если площадка недоступна, фиксирую сбой, а позиции с недостаточным покрытием сохраняют текущую цену.

После расчёта записываю рекомендацию, причину и версию входных данных. Уникальный ключ из ID запуска и артикула позволяет безопасно обработать результат повторно, а перед публикацией сверяю версию текущей цены, чтобы сохранить более свежую ручную правку. При `APPLY` передаю рекомендацию действующему генератору прайсов, а `REVIEW` направляю ответственному на проверку. Сначала сравниваю результаты новой системы с Excel на отмеченных артикулах, затем включаю публикацию для небольшой группы через переключатель. При проблеме переключаю запись обратно на Excel и при необходимости восстанавливаю последнюю проверенную версию прайса.

## 3. Расчёт и тесты

Python 3.10 или новее. Достаточно стандартной библиотеки.

```bash
python starter.py
python -m unittest -v
```

В примере получается `Decimal("4728.00")` и решение `APPLY`. Тесты проверяют сбои источника, границы допуска, округление и сохранение действующей цены при отсутствии подходящих предложений.
